# Arcana 1.0.0-beta.1

First public build of Arcana: a cross-platform archiver with a desktop GUI, a full CLI, 17 built-in engines and fallback read support for 240+ formats.

This is a **beta**. The archive paths are hardened and the test suite runs on Windows, Linux and macOS, but the installers, file associations and desktop integration have not been exercised on every distribution yet. Keep a copy of anything irreplaceable.

Every package is self-contained: no .NET runtime install is required.

### Windows

Unzip and run `Arcana.App\Arcana.App.exe`, or install with the `-setup.exe`. The installer is per-user (no admin prompt) and offers Explorer context-menu entries and an optional "Open with" association without taking over your default ZIP application.

### Linux

Unzip and run `Arcana.App/Arcana.App`. The `.deb` installs `arcana` (CLI) and `arcana-gui` (desktop) with a menu entry:

```bash
sudo dpkg -i Arcana-v1.0.0-beta.1-linux-x64.deb
```

### macOS

Open the DMG and drag Arcana to Applications. The bundle is ad-hoc signed, not notarized: the first launch needs right-click → Open, or `xattr -dr com.apple.quarantine /Applications/Arcana.app`.

## What is in the box

- **Formats:** ZIP, 7z, TAR (+gz/bz2/xz/zst), RAR, ISO, CAB, ACE, ARJ, LZH and the single-stream codecs (Gzip, BZip2, Xz, LZMA, LZ4, Zstd, Snappy, Brotli). Reading also falls back to ~240 further formats.
- **GUI:** archive browser, per-entry and archive-wide properties, in-place editing, previews (text, image, animated GIF, PDF, Office XML, hex), extraction wizard with conflict handling, paged extraction summary, themed icon sets, three UI themes.
- **CLI:** `compress`, `extract`, `list`, `convert`, `hash` (with `--verify`), `split` (with `--hjsplit`), `join`, `benchmark`.
- **Safety:** destination containment, link checks, CRC and length verification before publishing a file, atomic archive replacement, and progress that reports bytes so speed, ETA and the compression-ratio chart stay meaningful on huge archives.
- **Crypto:** AES-256-GCM with Argon2id for Arcana envelopes, WinZip-compatible ZIP AES-256 writing, password prompts with retry for reading.

## Known limits

- Encrypted **7z writing is disabled**; reading native encrypted 7z still works.
- The managed 7z, XZ and LZMA writers buffer input, so a single write is capped at 256 MiB. Use ZIP or TAR + Zstandard for larger jobs.
- Resource ceilings per operation: 64 GiB expanded, 100,000 VFS nodes, 128 path components.
- Cancelling an extraction keeps the files already written and removes the incomplete one.
- Windows packages are unsigned, macOS bundles are not notarized. SmartScreen and Gatekeeper will ask for confirmation.

Full capability list: `docs/PRODUCTION_READINESS.md`, shipped in every package as `RELEASE_NOTES.md`.
